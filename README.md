## Deskripsi
Proyek ini berisi latihan penggunaan string dan pengolahan teks menggunakan Python, serta tugas normalisasi data mahasiswa.

## Struktur Folder
- `latihan/01_dasar_string.py` — Dasar string.
- `latihan/02_indeks_slicing.py` — Indeks dan slicing.
- `latihan/03_method_string.py` — Method string.
- `latihan/04_bersihkan_teks.py` — Membersihkan teks.
- `latihan/05_split_join.py` — Memisahkan dan menggabungkan teks.
- `latihan/06_pencarian_kata.py` — Pencarian kata.
- `tugas/normalisasi_data_mahasiswa.py` — Normalisasi data mahasiswa.

## Algoritma Tugas
1. Memasukkan nama mahasiswa dan kode kelas.
2. Menghapus spasi berlebih pada nama.
3. Mengubah nama menjadi format title case.
4. Mengubah kode kelas menjadi huruf kapital dan memisahkan bagian kode dengan tanda hubung.
5. Menghitung jumlah kata dalam nama.
6. Membuat inisial dari setiap kata pada nama.
7. Menampilkan hasil normalisasi.

## Cara Menjalankan
Jalankan file Python melalui terminal VS Code menggunakan perintah:

`python latihan/01_dasar_string.py`

Untuk menjalankan tugas utama:

`python tugas/normalisasi_data_mahasiswa.py`
